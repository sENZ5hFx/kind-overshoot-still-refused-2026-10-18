# skill-creator

A class without a kill rule is a slogan. A refusal without the arithmetic is also a slogan.

Write:

- one-sentence remainder
- the kill that fired, with the numbers
- explicit "do not re-issue" list
- the leftover, still unminted

Do not mint the leftover in the same session that proved the rectangle is not yet printed.

An index extract is not the correction and not the table. If the PDF bytes were not hashed, say so and do not mark that source used up.
